# KMZ 密集軍議プロトタイプ

## 目的
実際の完成KMZ / KMLをブラウザ内だけで解析し、POI密集地点を検出してリクとミナの軍議を発火する最小試作です。

## 現在の判定
- 密集半径: 40m
- 発火最低数: 6 POI
- 休憩・支援候補の探索半径: 100m
- フォルダ名に `追加` / `希望` / `add` / `proposed` / `candidate` がある場合、その地点を追加POI候補として優先解析
- 追加POIレイヤーを識別できない場合は、Point形式の全POIで仮解析
- トイレ、水飲み、休憩、ベンチ、東屋、売店、カフェ、案内所などは支援候補として暫定認識

※ 閾値と名称判定はすべてプロトタイプ用です。本番仕様として確定したものではありません。

## 試し方
1. `prototype/kmz-density-test.html` をブラウザで開く。
2. 完成KMZまたはKMLを選ぶ。
3. 地図上へPOIが表示される。
4. 半径40m以内に6POI以上ある最も強い密集地点を探す。
5. 見つかった場合、その地点へ地図がズームして軍議が開始される。
6. 「次へ」でリク → ミナ → 周辺支援確認の順に進む。

## 表示色
- 青: 通常POI
- オレンジ: 追加POI候補
- 緑: 休憩・支援候補
- 赤 / オレンジの強調円: 今回の軍議対象となった密集地点

## セリフの思想
### リク
危険だから否定する役ではなく、リスクを分析して勝ち筋・改善策を探す参謀。

### ミナ
にぎわい、楽しさ、歩きたくなる理由など、同じ事実の魅力側を見る。

明確な危険地点では無理に対立させない。本プロトタイプではまず「密集」という、長所と短所が同時に成立する論点を検証する。

## セキュリティ
選択したKMZ / KMLはこの試作からサーバーへアップロードしません。JavaScriptでブラウザ内解析します。
