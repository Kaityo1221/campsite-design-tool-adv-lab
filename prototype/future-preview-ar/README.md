# Campsite 未来プレビュー AR Phase 1

Campsite Design Tool 本番とは分離した実験用プロトタイプです。

## 第一段階の範囲

- 完成 KMZ / KML をブラウザ内で読み込む
- `活動範囲` フォルダまたは Placemark の Polygon を抽出
- カメラ・端末方角・GPSを LocAR.js で開始
- 20 / 50 / 100 人を選択
- `未来を見る` を押した時だけ活動範囲内へ仮想人物を配置
- `VIRTUAL PREVIEW` を常時表示
- 保存・エクスポート機能なし
- `終了して破棄` でページを再読込し、仮想人物とARセッションを破棄

## 対象外

第一段階では以下を実装しません。

- 200 / 500 人表示
- 季節・時間帯・天候エフェクト
- 群れ方・歩行・会話アニメーション
- POIへ寄せる配置
- 滞留予測
- KMZへの書き戻し
- 画像保存・提出連携

## 開発

```bash
cd prototype/future-preview-ar
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
```

## 現地テスト

カメラ、GPS、端末方角を使用するため、iPhone SafariではHTTPS上で開いてください。

1. 完成KMZ / KMLを選択
2. 活動範囲が認識されたことを確認
3. `カメラ・位置情報を開始`
4. Safariのカメラ、位置情報、モーションと方向の許可を承認
5. GPS取得後、20 / 50 / 100人を選択
6. `未来を見る`
7. 人物の大まかな位置、方角、揺れを現地で確認

GPS精度が悪い場合は警告を表示しますが、第一段階では数十cm精度を合格条件にしません。

## データ方針

選択したKMZ / KMLはサーバーへ送信しません。ブラウザ内で解析します。仮想人物はKMZ・提出データへ保存しません。
