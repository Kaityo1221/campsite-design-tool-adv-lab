## 重要な発見

### 1. 判定範囲を先に絞る必要がある

イベント判定はCSV全域ではなく、キャンプサイトの活動範囲またはKMZで選ばれた対象POIだけに対して行う必要がある。広域POIをそのまま入れると、地域の特色ではなく単純な母数でイベントが大量成立する。

### 2. アート判定に偽陽性を確認

研究学園駅から700m以内の未分類61 POIで確認したところ、`シェアスペース ヴィアート` が `アート`、`古民家 つくばスタイル館` が `タイル` に部分一致してアート候補になった。

対策:
- `タイル` は名称単独判定から外す。
- `アート` は単純部分一致を弱め、明確なアート語・Lab Engine分類を優先する。

### 3. 交通判定に偽陽性を確認

`駅` の単純部分一致では `東横INN研究学園駅前` や `研究学園駅の駅ピアノ` まで交通POIになる。

対策:
- `駅$`、改札、バス停、乗り場など実交通施設を示す語へ絞る。
- `駅前` を含むだけの店舗・ホテル等は交通判定しない。

## 研究学園駅周辺 700m の縮小試験

未分類61 POI。

現行名称判定では主に `駅・交通アクセス / アート集中 / 寺社・宗教周辺` が成立しうる。

ただしアート集中は上記の部分一致偽陽性によるため、修正後は消える見込み。寺社候補の `葛城根崎八幡宮` は駅から約598mで実在POIとして名称判定上は妥当だが、実際のキャンプサイト活動範囲に入るかで最終判断する。

## V1の次の調整

1. 判定対象を活動範囲 / 選択KMZ内に限定する。
2. `アート` と `駅` の名称ルールを修正する。
3. 5地域を個別ケースとして再計測する。
4. LOOP / STAY / REST / CAUTION のLab Engine分類を結合して再計測する。
5. 密集系は追加POI・既存POIの区別が取れるKMZで検証する。

## 結論

24イベントの骨格はそのまま使える。最初の実データ投入で、イベント数そのものより先に「判定範囲」と「部分一致の偽陽性」を潰すべきことが分かった。これはV1の閾値調整前に直す。
