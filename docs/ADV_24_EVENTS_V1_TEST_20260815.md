## 重要な発見

### 1. 判定範囲を先に絞る必要がある

イベント判定はCSV全域ではなく、キャンプサイトの活動範囲またはKMZで選ばれた対象POIだけに対して行う必要がある。広域POIをそのまま入れると、地域の特色ではなく単純な母数でイベントが大量成立する。

### 2. アート判定に偽陽性を確認

研究学園駅から700m以内の未分類61 POIで確認したところ、`シェアスペース ヴィアート` が `アート`、`古民家 つくばスタイル館` が `タイル` に部分一致してアート候補になった。

対策:
- `タイル` は名称単独判定から外す。
- `アート` は単純部分一致を弱め、明確なアート語・Lab Engine分類を優先する。

### 3. 交通判定に偽陽性を確認

`駅` の単純部分一致では `東横INN研究学園駅前` や `研究学園駅の駅ピアノ` まで交通POIになる。

対策:
- `駅$`、改札、バス停、乗り場など実交通施設を示す語へ絞る。
- `駅前` を含むだけの店舗・ホテル等は交通判定しない。

## 研究学園駅周辺 700m の縮小試験

未分類61 POI。

現行名称判定では主に `駅・交通アクセス / アート集中 / 寺社・宗教周辺` が成立しうる。

ただしアート集中は上記の部分一致偽陽性によるため、修正後は消える見込み。寺社候補の `葛城根崎八幡宮` は駅から約598mで実在POIとして名称判定上は妥当だが、実際のキャンプサイト活動範囲に入るかで最終判断する。

## v0.2.2 反映

2026-08-15、一次試験で見つかった2系統の問題を先に修正した。

### 判定範囲

`detectAll()` の入力に以下のスコープを追加した。

- `activityPolygon`: 活動範囲ポリゴン内のPOIだけを判定
- `activityBounds`: 矩形範囲内のPOIだけを判定
- `scopePointIds`: 明示選択されたPOIだけを判定

テスト画面ではKMZ/KML内の `活動範囲 / 活動エリア / 活動区域 / 対象範囲 / 対象エリア` に相当するポリゴンを検出し、存在する場合はその内部だけを24イベント判定へ渡す。50m/40m/30m円やbuffer等は活動範囲として扱わない。

### アート偽陽性

- 名称単独ルールから `タイル` を削除。
- `アート` の任意部分一致を廃止し、明確なアート語または区切られた `アート` のみを名称判定に利用。
- 実データで確認した `ヴィアート` はアート判定から除外。

これにより `古民家 つくばスタイル館` と `シェアスペース ヴィアート` は名称だけではアート候補にならない。

### 交通偽陽性

- `駅` の任意部分一致を廃止。
- POI名が `駅` で終わる場合、または `station / 改札 / バス停 / 乗り場` 等の明確な交通語を持つ場合だけ交通候補にする。

これにより `東横INN研究学園駅前` と `研究学園駅の駅ピアノ` は交通候補から外れ、`研究学園駅` 自体は交通候補として残る。

## 結論

24イベントの骨格はそのまま使える。最初の実データ投入で、イベント数そのものより先に「判定範囲」と「部分一致の偽陽性」を潰すべきことが分かった。v0.2.2でこの2点をエンジン側に反映したため、次は5地域を活動範囲単位で再計測し、Lab Engine分類を重ねていく。
