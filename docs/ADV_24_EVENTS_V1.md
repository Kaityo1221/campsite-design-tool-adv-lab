## ストーリー設計

全イベントは基本的に `発見 → 状況を読む → 設計上の論点へ進む` の3段階で構成する。複合好条件のみ複数の好条件を順番に確認して総合評価へ進む。セリフ本文は実装しない。

## Lab Engine分類との接続

- `LOOP` → 回遊候補として利用
- `REST` → 休憩・支援候補として利用
- `STAY` → 活動・滞在候補として構成分析に利用
- `CAUTION` → 将来、確認型イベントの補助シグナルとして利用
- `HOLD / EXCLUDE` → V1ではイベント成立の積極材料にしない

## 2026-08-15 実データ確認
