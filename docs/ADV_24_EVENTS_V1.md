# ADV 24イベント V1

## 方針

- POIレビュー完了を待たず、高確度の名称・フォルダ判定で先行実装する。
- 人レビューで確定したPOI分類は、後から同じカテゴリ入力へ追加する。
- セリフ本文は未確定。イベントごとのストーリー骨格だけ先に固定する。
- 複合イベントが成立した場合は、単純イベントを抑制して二重発火を減らす。

## 複合イベントの抑制

- `DENSITY_REST_01` が出た場合、`DENSITY_01` を抑制。
- `FAMILY_01` が出た場合、`PLAYGROUND_01` と `REST_SUPPORT_01` を抑制。
- `CULTURE_WALK_01` が出た場合、`ART_01` と `HISTORY_01` を抑制。
- `WATER_REST_01` が出た場合、`WATER_01` と `REST_SUPPORT_01` を抑制。
- `ENTRANCE_DENSITY_01` が出た場合、`ENTRANCE_01` と `DENSITY_01` を抑制。
