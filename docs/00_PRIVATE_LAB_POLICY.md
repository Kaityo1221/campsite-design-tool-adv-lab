# Campsite Design Tool ADV Lab 開発方針

## 目的
Campsite Design Tool のチュートリアル／軍議型レビュー体験を、本体から独立して非公開で試作し、完成度が上がった段階で本体へ統合する。

## 秘密運用
- このリポジトリは Private のまま運用する。
- 公開本体 `Kaityo1221/Campsite-Design-Tool-JP` には、完成直前まで ADV 関連コードを入れない。
- ADV Lab から本体へは自動反映しない。
- 本体の変更は必要に応じて Lab 側へ追従する。

## 現在の同期基準
- 本体: `Kaityo1221/Campsite-Design-Tool-JP`
- 基準ブランチ: `main`
- 2026-08-11 時点の確認基準コミット: `965ab13bb8f592a675d31c4d73e5c728dcc5fe70`
- このコミットには現地モードのクリエイティブ固定マップ基盤、位置調整統合、IndexedDB 自動保存・復元、安全チェック基盤が統合されている。

## 開発段階
1. ADV の箱を独立試作する。
2. リク／ミナの軍議 UI を仮素材で動かす。
3. 距離チェック結果と軍議イベント判定を接続する。
4. 本番キャラクター素材へ差し替える。
5. ハル／レンを追加してチュートリアルと総評を完成させる。
6. 本体最新版との差分を吸収する。
7. 会長のみで最終確認する。
8. 本体へ統合する。

## キャラクターの基本原則
- リク: リスク、通行、安全、運用、改善策を分析する参謀。否定担当にはしない。
- ミナ: 魅力、楽しさ、にぎわい、歩きたくなる価値を見つける。
- 危険が明確な地点では無理に対立させず、全会一致で回避する。
- 同じ事実を複数の価値観から見せ、最終判断を利用者に押し付けない。

## 実装原則
- セリフは画像へ焼き込まず HTML/JS 側で描画する。
- キャラ素材とシナリオデータを分離する。
- 地図・距離チェック本体に ADV ロジックを直書きしすぎない。
- 最終統合時に `adv/` 単位で移植できる構造を維持する。
